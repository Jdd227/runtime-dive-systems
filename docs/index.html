Data sources

Bathymetry: Washington DNR 1 m CoNED MLLW raster, grayscale shaded relief, with close-zoom 20 ft contours.

Tides: NOAA CO-OPS predictions.

Currents: NOAA SSCOFS near-surface guidance with native wet-grid samples and local interpolation for display. Forecast time and data coverage shown explicitly. Do not infer near-shore or depth-specific conditions.

Planning aid only. Model guidance and bathymetry are not a substitute for navigation, site knowledge, or dive-team judgment.

RunTime Dive Systems · NOAA model currents are forecast guidance, not measurements. Missing or stale model data are deliberately hidden. Do not use this tool as primary navigation or for dive-decision thresholds.
